# Лабораторная работа №1 по Java

**Тема:** Создание программ на языке Java

## Структура проекта

* `Простое задание/` — программа перевода температур из градусов Цельсия в Фаренгейты и обратно (`TemperatureConverter.java`).
* `Сложное задание/` — программа для нахождения всех делителей числа и их общего количества (`DivisorsFinder.java`).
* `Инструкция по практическому заданию.txt` — описание выполненной работы и хода реализации.
