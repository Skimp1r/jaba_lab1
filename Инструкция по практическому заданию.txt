ИНСТРУКЦИЯ ПО ПРАКТИЧЕСКОМУ ЗАДАНИЮ

ОСНОВНОЕ ЗАДАНИЕ
Автор решения: Быстров Марк Андреевич

В рамках лабораторной работы №1 разработаны две консольные программы на языке Java, демонстрирующие применение базовых синтаксических конструкций, организацию ввода-вывода, ветвлений, циклов и вынесение логики в отдельные статические методы. Тема лабораторной работы — «Создание программ на языке Java». Цель — освоить базовые принципы разработки программ на Java, научиться работать со стандартными потоками ввода и вывода, типами данных, условными операторами if-else, циклами for и вспомогательными классами стандартной библиотеки (Scanner, Math), а также компилировать и тестировать консольные приложения на платформе Java SE (JDK). Исходный код программ компилируется утилитой javac в платформонезависимый байт-код (.class) и исполняется виртуальной машиной Java (JVM).

Первая программа — простое задание (TemperatureConverter) — представляет собой консольный конвертер температур между шкалами Цельсия и Фаренгейта. Для организации ввода данных из стандартного потока System.in используется объект класса Scanner. Пользователю выводится интерактивное меню выбора направления перевода: ввод единицы активирует ветку перевода из градусов Цельсия в градусы Фаренгейта по формуле F = C * 1.8 + 32, ввод двойки — обратный перевод по формуле C = (F - 32) / 1.8. Для выбора режима вычислений задействован условный оператор if-else if-else, в котором также предусмотрена ветка обработки некорректного выбора пункта меню. Значения температур считываются методом in.nextDouble(), что обеспечивает поддержку вещественных чисел двойной точности (тип double). Итоговый результат форматируется методом System.out.printf с округлением до двух знаков после запятой (спецификатор %.2f), гарантируя наглядность представления данных.

Вторая программа — сложное задание (DivisorsFinder) — выполняет нахождение и вывод всех натуральных делителей введенного целого числа, а также подсчет их общего количества. Архитектурно приложение разделено на метод входа main и статический вспомогательный метод printDivisors(int number), что соответствует принципам декомпозиции кода и демонстрационным примерам из методических указаний. Программа считывает целое число типа int с помощью in.nextInt(). В методе printDivisors исходное значение приводится к абсолютному с помощью Math.abs(number), что позволяет корректно обрабатывать отрицательные числа. Для нуля реализована граничная проверка (число 0 имеет бесконечное множество делителей). Поиск делителей осуществляется в цикле for со счетчиком i от 1 до temp: с помощью операции взятия остатка от деления (temp % i == 0) выявляются делители, которые последовательно выводятся в консоль через пробел с инкрементом счетчика count. По завершении цикла программа выводит суммарное число найденных делителей.

В обоих проектах соблюдена стандартная модель выполнения консольных Java-приложений: точка входа public static void main(String[] args), использование классов Scanner для буферизованного чтения из System.in и методов System.out.print / println / printf для отображения данных. Корректность работы подтверждена компиляцией исходных файлов TemperatureConverter.java и DivisorsFinder.java с помощью javac с кодировкой UTF-8 и их выполнением на JVM. Таким образом, работа полностью охватывает типовые операции консольного ввода-вывода, ветвления, циклы и процедурную декомпозицию в среде Java.
